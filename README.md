 IPL  Analytics – SQL Practice

 
 
This project focuses on analyzing IPL (Indian Premier League) player data using **MySQL**. It contains SQL queries designed to explore player prices, teams, roles, player categories, and team-wise statistics.

The goal is to improve SQL skills by solving practical, real-world data analysis questions.
Dataset Information

The dataset contains IPL player details with the following columns:

| Column Name | Description |
|---|---|
| Player | Name of the player |
| Price_in_cr | Player price in crores |
| Type | Indian / Overseas player category |
| Acquisition | Retained or Auction |
| Role | Batter, Bowler, All-rounder, etc. |
| Team | IPL team name |

Technologies Used
- MySQL
- MySQL Workbench
- SQL




Project Objective

- Strengthen SQL fundamentals.
- Practice solving analytical problems.
- Improve problem-solving and query-writing skills.
